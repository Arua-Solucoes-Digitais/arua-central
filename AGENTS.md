## Project rules

- All homepage copy lives in `src/content/site.ts`; sections render from it so text can be edited without touching layout.
- Projects live in the `base_projects` table, edited at `/admin`; only rows with status `published` reach the public site. Never hard-code a product on the homepage.
- Portfolio: `base_projects.kind` is `product` (Aruá's own, shown on the homepage) or `case` (client work, portfolio only). Live systems live in `deployments`; the public state ("No ar"/"Fora do ar") is always computed from the last automatic check (`npm run status`), never typed by hand.
- Testimonials and client results must be real: a testimonial is published only with `authorized = 1` (enforced by the database). Never seed or invent them.
- Aruá Hospedagens: `properties` is the tenant. Every query for stays, media or requests must be scoped by `property_id`, and commercial data belongs in the database, not in code.
- Publishing means changing a row in the database of that server. Local data never reaches production by itself, so never report something as online without checking the online site.
- To change the database structure, append to `MIGRATIONS` in `src/server/db.ts`; never edit a migration already used.
- Brand colors/fonts are tokens in `src/styles.css` (`--aru-*`); components use semantic classes only.
- The project runs without external services: data lives in SQLite at `data/arua.db` (never versioned) and browser code reaches it only through server functions in `src/lib/api.ts`, which check permission on every call.
- Admin access = row in `users`; there is no public signup, admins are created or reset in the terminal with `npm run admin`.
- Analytics are first-party and anonymous (`analytics_events`: no cookies, IP or user id); tracked clicks use `data-track="label"`.
- Static demo (GitHub Pages): `npm run build:demo` swaps `src/lib/api.ts` for `src/demo/api.ts` (sample data from `src/demo/snapshot.json`, no writes). Every new export in `src/lib/api.ts` needs a stand-in there; `src/demo/api.test.ts` enforces it. The snapshot is built from a fresh database plus `src/demo/projects.json`, which `npm run demo:export-projects` exports from `data/arua.db` with only published projects and public fields; never put anything else from `data/arua.db` into the demo.
- Example landing pages: `public/demos/<slug>/index.html`, one self-contained file each (no external assets, `noindex`, under 20 KB), always a fictional business, loading `public/demos/arua-preview.js` (blur, "Modo demonstração" mark, "Voltar à Aruá"). They are shown inside the site at `/exemplos/<slug>` with a phone/tablet/computer switch (`src/content/examples.ts`, `ExampleViewer.tsx`). WhatsApp in examples is always Aruá's. Real client material only with the owner's written authorization recorded in `docs/demos/<slug>.md`. A `public/demos/<slug>/property.json` still becomes an Aruá Hospedagens showcase; today there is none and the Aruá Hospedagens demo is `/exemplos/pousada` (migration 5).
- Prices: no price appears on the public site until the values are announced (decision of 17/11/2026). Plans show `COMING_SOON` ("Em breve") from `src/content/site.ts`; `src/content/site.test.ts` enforces it. Demos never show prices or proposal values.
- Client area: `/area-do-cliente` only explains what is coming ("Em breve"); there is no client login yet.
- Tlim demo (`/demonstracoes/tlim`, `/demonstracoes/tlim/loja`): Aruá's own product, original code (never derived from third-party code without a license). Data in `src/content/demos/tlim.ts` (contract in `types.ts`, registry and copy in `index.ts`), screens in `src/components/demos/`, shared in-memory state in `tlim-store.ts` (an order placed on the online menu reaches the order center in the same visit). The example restaurant is fictional; real numbers carry their source and date; menu, prices, customers and orders are simulation. Nothing is saved, sent, charged or published, and no `localStorage`. Sources in `docs/demos/tlim.md`.
- Every demo page shows the Aruá brand: header with the Aruá logo, the signature (`signature` in `src/content/demos/index.ts`, Aruá + CjotaDEV7) and the fixed watermark with a "Voltar à Aruá" button (`DemoWatermark`; `arua-preview.js` on static client sites).
- Public domain site: `aruasolucoes.com.br` is the static build (`npm run build:site`, `IS_PUBLIC_SITE` in `src/lib/demo-mode.ts`) served by the Cloudflare Worker `arua-central` (`wrangler.jsonc`, headers in `deploy/cloudflare/_headers`). Contact goes to Aruá's WhatsApp; nothing is stored. Publish with `npm run deploy:site`, only with the owner's approval. Copy there must not promise what does not exist (no invoices, payments, automation or customers).
- Real site deploys to a VPS over SSH (`deploy/`, `.github/workflows/deploy.yml`); see `docs/DEPLOYMENT.md`. Production deploys need the typed `PRODUCAO` confirmation and an actor in `PRODUCTION_APPROVERS`. The demo is published to Pages only by manual run with `PUBLICAR`.
