# Páginas de exemplo

| Página | Endereço na vitrine | Arquivo | Produto que ilustra |
|---|---|---|---|
| Burger do Bairro | `/exemplos/restaurante` | `public/demos/restaurante/index.html` | Site de restaurante, com atalho para o cardápio do Tlim |
| Pousada Serra Clara | `/exemplos/pousada` | `public/demos/pousada/index.html` | Aruá Hospedagens: pedido de reserva pelo WhatsApp |

- Os dois negócios são **fictícios**. Não há fotos, textos, preços ou dados de clientes; as ilustrações são SVG e CSS feitos para estas páginas.
- Escritas em 26/11/2026, no lugar dos projetos anteriores de clientes, encerrados pelo responsável.
- O cardápio do restaurante repete valores simulados do Tlim (há um teste). A pousada não mostra diárias.
- O pedido de reserva não é salvo; o botão abre o WhatsApp **da Aruá**, com a mensagem marcada como demonstração.
- Para a reunião: abra `/exemplos/<nome>`, escolha Celular, Tablet ou Computador, ou use **Abrir em tela cheia**.
